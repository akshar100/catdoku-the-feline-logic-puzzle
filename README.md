# Catdoku PWA

A feline logic puzzle game combining Sudoku & Star Battle mechanics.

## Rules
1. Exactly one 🐱 per row.
2. Exactly one 🐱 per column.
3. Exactly one 🐱 per color region.
4. Cats cannot touch each other horizontally, vertically, or diagonally.

## Deployment
Upload all files directly to GitHub Pages, Cloudflare Pages, Netlify, or run locally via `npx serve .`.
